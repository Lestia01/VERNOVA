System Architecture

How data travels from the camera to the cloud.

1 · Computer Vision

TensorFlow.js + Teachable Machine classify every object in the browser with a confidence threshold of 85%.

2 · ESP32 Wi-Fi REST Bridge

The browser dispatches a structured JSON payload over HTTP REST API to the ESP32 endpoint (/api/sort).

3 · ESP32 Robot Brain

The ESP32 parses the JSON command, drives sorting servos, and returns an instant JSON acknowledgment.

4 · Handshake & QC

A 12-second watchdog timer flags any missing acknowledgement as a timeout error for quality control.

5 · Realtime Database

Firebase RTDB stores each event with a timestamp; every connected dashboard stays in sync instantly.

6 · Rich Reporting

Styled XLSX, PDF and DOCX reports with the R-LAB header, colour-coded rows and full summaries.
